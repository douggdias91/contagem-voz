# Contagem por Voz MB52 - Mobile v13

Versão ajustada para celular/tablet e preparada para GitHub Pages.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub (ex.: `contagem-voz`).
2. Envie `index.html`, `404.html`, `.nojekyll` e este `README.md` para a raiz do repositório.
3. Abra **Settings > Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e abra o endereço HTTPS informado pelo GitHub Pages.

## Importante para voz no celular
- Abra pelo endereço `https://...github.io/...`.
- Não abra o arquivo `index.html` diretamente no armazenamento do celular (`file://`).
- No primeiro uso, permita o microfone para o site.
- Toque em **Iniciar voz** e aguarde o status **OUVINDO** antes de falar.
- Fale o material e a quantidade.
- Toque em **Encerrar voz** para revisar e depois em **Salvar contagem**.

No Chrome Android, o reconhecimento de voz pode encerrar a sessão após uma pausa. Se isso ocorrer depois de captar a fala, o app preserva a transcrição e abre a prévia em vez de reiniciar o microfone.
